# ShynWorks

> **A cleaner space. A better experience.**

ShynWorks is a modern cleaning service website designed to give a professional cleaning brand a strong digital presence. The website presents cleaning services, communicates the company's value, and provides visitors with a simple and engaging way to explore the services offered.

**Live Website:** https://shyn-works.vercel.app/

---

## About the Project

ShynWorks was built with a focus on **clean design, simplicity, and user experience** — reflecting the same qualities expected from a professional cleaning service.

The interface combines a modern visual style with responsive layouts, clear service presentation, and engaging interactions to create a trustworthy experience for potential customers.

## Getting Started

Clone the repository:

```bash
git clone https://github.com/webfyredev/ShynWorks.git
```

Navigate into the project:

```bash
cd ShynWorks
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Open **http://localhost:5173** in your browser.

---

## Production Build

```bash
npm run build
```

Preview the production build:

```bash
npm run preview
```
